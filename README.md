# Biblioteca Virtual UTP (IHM · PA3)

HTML + CSS + JavaScript puro en el navegador, Node + Express en el servidor, sin base de datos (los datos están en `data/*.json`).

## Cómo ejecutarlo
```
npm install
npm start
```
Abrir http://localhost:3000 (entrar con cualquier correo `@utp.edu.pe` y una clave de 6+ caracteres).

Para empezar de cero las reservas: dejar `data/reservas.json` con `[]`.
